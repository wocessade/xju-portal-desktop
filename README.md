# 新大研究生办事大厅 · 转接桌面（公共版）

用一张网页把研究生要用的办事入口全整理好了：点一下直达对应官方系统，不用在办事大厅里翻来翻去，也不用再问学长"XX系统在哪"。

**在线打开（不用下载）**：
- 研究生版：<https://wocessade.github.io/xju-portal-desktop/>
- 本科生版：<https://wocessade.github.io/xju-portal-desktop/undergrad/>

手机浏览器、电脑浏览器都能开；也可以下载对应 `index.html` 后双击直接打开。

## 怎么用（30 秒上手）

1. 打开网页，看到一堆小卡片。
2. 点卡片 → 新窗口打开对应**官方系统** → 用**你自己的学号密码**登录。
3. 想找功能就点右上角搜索框，输入"缴费""请假"等关键词。
4. 页面分三层：
   - **★常用**置顶：最常点的 10 个（缴费、请假、一卡通、查方案……）；
   - 中间按类别分组：学生办事 / 教学培养 / 生活服务 / 网络与账号 / 公共服务 / 学术科研；
   - 页底**"更多低频入口"**：密码找回、冷门申请、应急类，平时折叠着，搜索时自动展开。
5. 卡片小字是提示："仅校内网"= 只有连学校网络才能打开；"首次进入需填…"= 系统要求补一次信息。

**安全说明**：本页是纯目录页——**不收集、不存储任何账号密码，页面上没有登录框**。你的密码永远只输在官方系统自己的页面里，网页只是导航站。

## 有些事在线办不了

没有在线入口的窗口类事项（盖章、补材料、缴费确认单等）整理在《线下办理指引.md》：哪个部门、咨询电话、几号窗口，共 49 条（这鬼玩意在官网上各有一个单独的网页）。

## 为什么做这个（脏话警告）

因为新大办事大厅吧……做这 48 个入口时顺手记了几笔账：

- 官方目录翻出来他妈 **270 条入口**，过滤掉教职工专用、本科专用、访客系统、打不开的死链之后，**研究生版只剩 48 个、本科生版 54 个**（两版去重不到 60 个）——剩下八成基本是摆设。
- 每个系统都是**独立的一套账号登录**：学工一个、教务一个、一卡通一个、图书馆一个、财务又一个。校领导回家每个屋子单独一个钥匙开门。
- "办事大厅"名字起得挺气派，可入口散在**十几个域名**里：authserver、frsys、yjspy、xdxg、xdtw、xdxglx、321、xljk、newcard、pay、sign、ot……这是打算学苏联搞分裂吗。
- 不少系统**只能在学校网络里打开**（学位论文系统、实验室安全、AI 平台……），宿舍和实验室的网络环境还不一样，这个没办法，卡片上只能标"仅校内网"自求多福。
- **校历**。官方校历页到现在还挂着 **2025-2026 学年第二学期**的图，9 月开学了它还没换（2026-08-28 亲测，图里白纸黑字写着上一学年）。
- 新疆大学的行政效率和人文关怀从来不让人失望 欢迎报考南京邮电大学。

  所以有了这个桌面：把能用的入口捞出来、分类、加提示。少为了那帮做网页的SB擦屁股。

## 维护与更新

- 入口增删改：编辑 `sites.json`（`id` 编号 / `name` 名称 / `group` 分组 / `url` 官方链接 / `notes` 卡片小字 / `tier`：`hot`=★常用、`low`=折叠低频、不写=常规分组），然后运行：
  ```
  node tools/build_desktop.cjs        # 研究生版 -> index.html
  node tools/build_desktop.cjs --ug   # 本科生版 -> undergrad/index.html（数据在 sites-ug.json）
  ```
- 本科教务系统（jwxt）系入口 2026-08-28 校外探测超时，已标「疑似仅校内网」——同学们主要在校园网里用，校外打不开属预期，不是 bug，等进校后可复测补验。
- 官方目录变动以学校为准；本页是 2026-08-28 的一次性快照，可能过时，发现问题欢迎提 issue。
- 页面设置了 `no-referrer`：学校统一认证平台只放行校内来源页的链接（2026-08 实测），从外部托管点过去会 404，故打开磁贴时不发送来源页信息。这是有意为之，不要删。
