# 新大研究生办事大厅 · 转接桌面（公共版）

把新疆大学网上办事服务大厅（rhmh.xju.edu.cn）目录里**研究生可用的在线入口**整理成一张静态桌面：48 个磁贴、6 个分组、可搜索；另有《线下办理指引.md》收录 49 条无直链的窗口类事项（含咨询电话）。

**安全边界**：本页是纯静态目录页——**不收集、不传输、不存储任何账号密码**，页面中没有任何登录框。点击磁贴后进入的是各官方系统，登录都在官方页面用你自己的学号密码完成。

## 使用

- 在线版：<https://wocessade.github.io/xju-portal-desktop/>（GitHub Pages，手机/电脑直接打开，无需下载）。
- 直接双击 `index.html` 即可（无需服务器）；或放到任意静态托管（校内网 / Tailscale 分享）。
- 点击磁贴 → 新窗口打开官方入口 → 用自己的学号密码登录（首次各系统分别登录一次，浏览器记住登录态后免重复）。
- 卡片小字是提示：`疑似仅校内网` / `需在宿舍区网络` 表示该入口只在相应网络可访问；`首次进入需填…` 是系统要求的信息补录。
- 无直链事项查《线下办理指引.md》。

## 维护

- 增删改入口：编辑 `sites.json`（字段：id 编号 / name / group 分组 / url 官方链接 / notes 提示 / tier 可选：`hot`=置顶★常用、`low`=折叠低频，缺省常规分组），然后运行：
  ```
  node tools/build_desktop.cjs
  ```
  会重新生成 `index.html`（模板 `template.html` 中的 `/*__DATA__*/ const SITES = [];` 是注入占位符）。
- 分组名即 `group` 字段值；搜索会匹配名称与 notes。

## 数据来源

- 2026-08-28 从官方服务目录两页（#/servicelist、#/list）抓取 270 条并集，过滤教职工专用/本科专用/访客/死链/无直链后保留在线可用项；再以登录态逐条复查跳转链与落地（剔除 4 条实际不可用：教学质量管理平台无账号、体测打卡证书无效、AI 平台两条错链），复查截图与清单见本地存档（未随仓库发布）。
- 官方目录若变动，以学校网站为准；本页为一次性快照。
